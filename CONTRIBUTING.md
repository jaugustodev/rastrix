# Contributing to Rastrix

Thanks for your interest. Rastrix is in early development, so the best way to help right now is to open an issue with ideas, questions or feedback.

## Workflow

1. Create a branch from `main`: `feat/short-name`, `fix/short-name`, `chore/short-name` or `docs/short-name`.
2. Commit using [Conventional Commits](https://www.conventionalcommits.org/), for example `feat(agent): add max steps per investigation`.
3. Open a pull request using the template.
4. CI must pass. Pull requests are squash merged.

## Releases

Releases follow [Semantic Versioning](https://semver.org/).

## Code of conduct

Be respectful and constructive. Assume good intent.
